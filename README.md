## SEO
The site includes:
- SEO title and meta description
- Canonical URL placeholder
- Open Graph and Twitter metadata
- Person JSON-LD structured data
- robots.txt
- sitemap.xml
- Semantic H1/H2/H3 structure
- Image alt text
- Crawlable, server-rendered HTML content

## Vercel
Deploy the folder as a static site. Before deployment, replace `YOUR-DOMAIN.com` in:
- `index.html`
- `robots.txt`
- `sitemap.xml`

with your actual custom domain.

## Important
Client-side HTML/CSS/JS cannot be made truly secret after deployment because browsers must receive the code. For SEO safety, keep the human-readable page content in HTML and only minify/obfuscate non-SEO JavaScript if desired.
